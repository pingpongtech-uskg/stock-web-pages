# 成長股估值契約

版本：`growth-total-return-pe-v1`

## 目的

成長股頁的主估值使用陳喬泓影片版「總報酬本益比」整理方法。祖魯 PEG 仍保留為所有策略的交叉參考，但不作成長股主排序或主合理價。

## 公式

```text
保守獲利成長率 = 多年度 EPS 成長率 × 0.8
總報酬率（百分點） = 保守獲利成長率 × 100 + 已確認現金股利殖利率 × 100
總報酬本益比 = 總報酬率（百分點） ÷ 目前 PE
Forward EPS = TTM EPS × (1 + 保守獲利成長率)
影片版情境合理價 = Forward EPS × 總報酬率（百分點）
低估參考價 = Forward EPS × (總報酬率（百分點） ÷ 1.2)
```

門檻：

- `總報酬本益比 >= 1.20`：低估研究候選
- `0.80 <= 總報酬本益比 < 1.20`：合理區，不列低估候選
- `< 0.80`：估值偏高，不列候選

## 輸入政策

- EPS 成長優先使用至少四個完整年度的多年度 CAGR。
- 不把單期 LTM EPS 暴增當作可持續預估。
- 營收成長不代替獲利成長。
- 現金股利資料缺失是 `unavailable`，不能補成 0；只有官方明確回傳 0 才算不配息。
- 成長率超過 100%，或合理價超過現價 3 倍，標記極端外推，不發布主合理價。
- 極端資料可留在 evidence/detail，不得進入成長股主候選。
- TTM EPS 只加總四個唯一、連續且口徑可比的季度；缺季、股票股利後未確認同股本基礎或口徑不一致時保留 unavailable 與原因。股票股利防護包含盈餘及資本公積來源。
- 當日官方 PE 缺失時，僅由同日原始收盤價除以正的有效 TTM EPS 推導，來源標記 derived；調整價或不同交易日不能代替。
- 股息須有截至資料日已確認的完整公告日期；選最新已確認的歷史年度，年度、四季或上下半年完整組合才能加總，並保留 sourcePeriod。分開的民國年度與「上半年／下半年」正規化後使用。缺失或僅月份日期不能認定為已確認零股息。

## 選股與覆蓋率

成長候選須同時通過總報酬本益比 1.20 門檻，以及五項實際健檢中至少四項 pass。檢核名稱必須為五個不同的既定項目；aggregate status 不作額外門檻。4 pass + 1 fail、4 pass + 1 unknown 均可入選；unknown 不計入 pass。月營收項目仍要求三個連續月份 YOY 為正，沒有額外 15% 營收門檻。

低檔觀察獨立使用有效價格回歸：`signalEligible=true`、Z ≤ 0 且斜率為正；財報健檢、EPS 及估值缺失不排除此觀察策略。

`funnel.version` 保留既有策略契約；財務覆蓋診斷使用 `funnel.growthCoverageVersion=growth-coverage-v1`。`growthEvaluationState`、各計算階段數量及 `growthTerminalOutcomes` 分辨缺資料、已知無效、極端、未達估值門檻、健檢未通過及最終入選。終端分類互斥，合計等於官方普通股母體；缺少的個股也計入 missing。`growthMissingReasons` 是可重疊的缺失統計，不能相加當作股票總數。

覆蓋診斷與 NA 顯示不改變排序。真實資料至少一檔可計算，且選股聯集、export 與歷史契約通過，才可證明管線可運作；最終候選可合法為零。離線 fixture 通過不代表已完成正式來源的現場驗收。

## UI 政策

- 成長股主欄位顯示影片版總報酬本益比、影片版情境合理價、低估參考價。
- 祖魯 PEG 顯示為「祖魯 PEG 交叉參考」。
- 成長股頁不顯示董監／籌碼參考區塊；籌碼資料不參與成長股估值或排序。
- 董監正式資料在其他策略／個股 detail 仍遵守 unknown fail-closed。
