# 研究協議

研究目標與軟體驗收分離。CAGR 50%／最大回撤 30% 只有在固定規則、point-in-time 母體、財報 first_seen、公司行動、成本與樣本外區間都可靠時才可評估。

比較至少四組：只投信入口、三入口無轉強、完整三入口＋品質＋低位＋轉強＋風控、全市場完整資料基準。任何近似可得時間要標 `approximate_availability`；資料不完整輸出 `not_evaluable`，不挑最好版本。

訊號在收盤後成立，下一個可交易日執行。正式模型不提供盤中停損監控、不串券商、不虛構停牌或漲跌停成交。
# 可用資料與替代策略（2026-09）

本發布範圍固定追蹤 `config/tracked_symbols.json` 的 A 母體：公開投信十日買超前 100。`scripts/fetch_research_universe.py` 每日保存來源排行與原始名次，所有策略都在這 100 檔上執行，投信排行不會再從子集合重算。yfinance 在發布器端提供 `auto_adjust=False` 的 `Adj Close` 與最新年度財報欄位；TWSE/TPEx OpenAPI 提供全市場公開財務快照。瀏覽器只讀靜態快照，不接觸 token 或外部金融 API。

五線譜使用固定 3.5 年日資料窗的 OLS 中線與 ±1/±2 個殘差標準差；調整價可取得時，Z 與圖表以 yfinance Adj Close 計算並標示來源。Yahoo 失敗時仍計算未調整 close proxy，供行情研究，但 `signalEligible=false`。

正式品質條件（三年獲利、CFO、ROE 中位數、槓桿）需要 point-in-time 與公告日，目前保留 `unknown`。為了讓研究入口有用，個股頁另列最新年度淨利、營業現金流、營業利益率、ROE、淨負債／EBITDA 五項代理，逐項顯示數值、期間、來源和通過／未通過；代理不能升級正式進場訊號。

成長策略以三月合計營收年增 ≥15% 作為營收代理，投信策略以十日淨買超與該股成交占比排序，低位榜只列調整價 Z≤0 的正向回歸位置。另提供低基期成長與低基期品質兩條獨立代理路徑：共同要求合格調整價、Z≤−1、正向 slope；成長路徑要求三月合計營收年增 ≥15%，品質路徑要求最新年度淨利與 CFO >0 且五項品質代理至少 4/5。投信名次只作排序與上下文，不能淘汰低基期候選。所有低基期列保留逐項 gate 原因並標示 `proxy`。這些入口允許研究候選存在；正式進場仍需要歷史八週證據、公告可得性、品質與公司行動全部通過。沒有 point-in-time 母體、成本與樣本外回測時，績效狀態固定為 `not_evaluable`。
