# 研究協議

研究目標與軟體驗收分離。CAGR 50%／最大回撤 30% 只有在固定規則、point-in-time 母體、財報 first_seen、公司行動、成本與樣本外區間都可靠時才可評估。

比較至少四組：只投信入口、三入口無轉強、完整三入口＋品質＋低位＋轉強＋風控、全市場完整資料基準。任何近似可得時間要標 `approximate_availability`；資料不完整輸出 `not_evaluable`，不挑最好版本。

訊號在收盤後成立，下一個可交易日執行。正式模型不提供盤中停損監控、不串券商、不虛構停牌或漲跌停成交。
# 可用資料與替代策略（2026-09）

本發布範圍固定追蹤 `config/tracked_symbols.json` 的 8 檔。FinMind 提供官方台股資訊、未調整價量、投信十日、月營收與財報；yfinance 在發布器端提供 `auto_adjust=False` 的 `Adj Close` 與最新年度財報欄位。瀏覽器只讀靜態快照，不接觸 token 或外部金融 API。

五線譜使用四年日資料的 OLS 中線與 ±1/±2 個殘差標準差；調整價可取得時，Z 與圖表以 yfinance Adj Close 計算並標示來源。Yahoo 失敗時仍計算未調整 close proxy，供行情研究，但 `signalEligible=false`。

正式品質條件（三年獲利、CFO、ROE 中位數、槓桿）需要 point-in-time 與公告日，目前保留 `unknown`。為了讓研究入口有用，個股頁另列最新年度淨利、營業現金流、營業利益率、ROE、淨負債／EBITDA 五項代理，逐項顯示數值、期間、來源和通過／未通過；代理不能升級正式進場訊號。

成長策略以三月合計營收年增 ≥15% 作為營收代理，投信策略以十日淨買超與該股成交占比排序，低位策略以調整價 Z≤0 且斜率為正排序。這些入口允許研究候選存在；正式進場仍需要歷史八週證據、公告可得性、品質與公司行動全部通過。沒有 point-in-time 母體、成本與樣本外回測時，績效狀態固定為 `not_evaluable`。
